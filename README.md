# CodeDoc AI 🤖

O **CodeDoc AI** é uma ferramenta web para desenvolvedores onde o usuário cola um código e a ferramenta gera automaticamente documentação inline, resumos de lógica e arquivos README profissionais.

> Criado com Synkra AIOX

## 🚀 Status do Projeto
O projeto está na fase inicial de desenvolvimento. A infraestrutura base com **Next.js**, **TypeScript** e **App Router** já foi configurada seguindo os padrões AIOX.

## 🛠️ Tecnologias
- **Framework:** Next.js 15
- **Linguagem:** TypeScript
- **Estilização:** CSS Modules (Vanilla CSS approach)

## 🏁 Como Rodar
1.  Instale as dependências:
    ```bash
    npm install
    ```
2.  Inicie o servidor de desenvolvimento:
    ```bash
    npm run dev
    ```
3.  Acesse [http://localhost:3000](http://localhost:3000)
