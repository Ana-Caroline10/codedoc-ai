# Story 1.3: Integração com a API do Gemini para Processamento de Código

## Story Statement
Como desenvolvedor, quero integrar o SDK do Google Generative AI ao backend (API Route) para que o código enviado pelo usuário seja processado e retorne documentação, resumos e READMEs automáticos.

## Acceptance Criteria
1.  [x] SDK `@google/generative-ai` instalado e configurado.
2.  [x] Rota de API `src/app/api/process/route.ts` implementada para receber código e linguagem.
3.  [x] Lógica de prompt estruturada para solicitar à IA:
    - Código comentado (inline).
    - Resumo da lógica em linguagem natural.
    - Lista de funções detectadas.
    - Conteúdo para um arquivo README.md.
4.  [x] Resposta da API formatada como um objeto JSON estruturado.
5.  [x] Tratamento de erros para falhas na API de IA ou chaves inválidas.
6.  [x] Frontend enviando dados reais e recebendo a resposta da IA (exibindo no console para validação inicial).
