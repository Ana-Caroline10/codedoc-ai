# Story 1.2: Implementação da Interface Principal e Editor de Código

## Story Statement
Como usuário, quero ter uma interface limpa e intuitiva com um editor de código onde eu possa colar meu código fonte e selecionar a linguagem, para que eu possa iniciar o processo de documentação automática.

1.  [x] Componente `CodeEditor` criado com um campo de texto (`textarea`) expansível ou com scroll.
2.  [x] Componente `LinguagemSelector` implementado com suporte a JavaScript, TypeScript e Python.
3.  [x] Estado da aplicação gerenciado via React Hooks (armazenando o código colado e a linguagem selecionada).
